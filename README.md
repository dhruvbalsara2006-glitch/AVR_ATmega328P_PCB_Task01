# AVR ATmega328P PCB Design using KiCad

A custom PCB design for the **ATmega328P microcontroller** created using **KiCad** as part of a PCB Design assignment. This project demonstrates schematic capture, PCB layout, component placement, and routing while following basic PCB design principles.

---

## 📖 Project Overview

This project focuses on designing a PCB for the **ATmega328P**, one of the most widely used AVR microcontrollers. The design includes the essential circuitry required to interface with the microcontroller and serves as a foundation for embedded system development.

---

## ✨ Features

- PCB designed using **KiCad**
- ATmega328P-based circuit
- Schematic capture
- PCB layout and routing
- Organized project files
- ATmega328P datasheet included

---

## 🛠️ Tools Used

- **KiCad**
- **ATmega328P Microcontroller**
